# FAQ

## About the app

**Is it free?**
Yes. There is no subscription and no credits. You pay nothing to draw icons.

**Does it need the internet?**
Only once, to download the 17.2 GB model. After that it works offline.

**Is my data sent anywhere?**
No. The pictures are made on your PC. Your words stay on your PC.

**Do I need ComfyUI or Python?**
No. Icon Forge has everything inside it.

**Which computers work?**
Windows 10 and 11 (64-bit) with a graphics card that supports Vulkan. Mac and Linux are not supported yet.

**Do I need an NVIDIA card?**
No. NVIDIA, AMD and Intel cards can work. We tested on an NVIDIA laptop card, so we cannot promise the same speed on others.

**Can I copy and paste in the text boxes?**
Yes. Right-click in any box for **Cut, Copy, Paste** and **Select all**. Ctrl+C and Ctrl+V work too.

## About the speed

**How long does one icon take?**
About 40 seconds on our test PC (8 GB graphics card). The first one takes about a minute longer.

**Why is the model so big?**
It is the AI's "brain". 17.2 GB is a normal size for a good picture model.

**Can I stop while it draws?**
Yes. Press **Stop generating**. Icons already drawn are kept.

## About the icons

**What format are the icons?**
SVG. They stay sharp at any size.

**Can I change the colour?**
Yes. In a font, use CSS `color`. For SVG files, edit the fill in any SVG editor.

**Can I use the icons in my own projects?**
The model (Flux Schnell) uses the Apache 2.0 licence, which allows it. AI picture rules differ in each country. If it matters for your work, check the rules where you live.

**Can I use my own SVG files?**
Yes. Put them in a folder inside `Documents\Icon Forge`. See [Your files](Your-Files.md). One-colour icons work best.

**Why do some icons look odd?**
The AI is not perfect. That is why step 2 lets you choose. You can also press **Make 5 more**.

## About your library

**How do I delete icons or a whole set?**
Open the [library](Library.md). Tick icons and press **Delete N from library…**, or press the small bin on a set. Files go to the Windows Recycle Bin, so you can restore them.

**What is the difference between "Remove" and "Delete"?**
**Remove from basket** only takes an icon out of your basket. The file stays in your library. **Delete from library** moves the file to the Recycle Bin.

**How do I keep the icons for one project together?**
Make your own set with **+ New set** in the [library](Library.md#make-your-own-set). Then copy or move icons into it. In Step 3 (Basket and font), **New set from basket…** saves your whole basket as a new set.

**Can I change an icon I already made?**
Yes. Pick it and use [Vary an icon](Vary-an-Icon.md). Change the words and the AI draws new versions. Your original is kept.

**Is my prompt saved?**
Yes, inside each new icon's SVG file. It is left out when you copy an icon or download a zip. See [Your files](Your-Files.md).

**Can I get all my icons as one file?**
Yes. In Step 3 (Basket and font), press **Download as zip**. The zip holds your SVG icons and the font files too. See [Step 3](Step-4-Basket-and-Font.md).

## About the font

**What do I get?**
`.ttf`, `.woff`, `.woff2`, a `.css` file and a preview page. See [Use your font](Use-Your-Font.md).

**Can I have more than one colour in a font icon?**
No. Font icons are one colour. Use the SVG files if you need more.
